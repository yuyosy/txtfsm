# TxtFSM

An independent TypeScript implementation of [TextFSM](https://github.com/google/textfsm), providing a parser library and a command-line interface.

The original project is licensed under the Apache 2.0 License, and this implementation follows the same license; as far as the author has verified, it is compatible with the original TextFSM templates.
